## ⚡ Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js 22+
- npm
- Git

### 1. Clone Repository

```bash
git clone https://github.com/masoomraja/my-portfolio.git
```

### 2. Navigate to Project

```bash
cd my-portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open the local URL printed by Vite, usually:

```text
http://localhost:5173
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```

## 🐳 Docker Deployment

This project supports containerized production deployment using Docker and Nginx.

### Run with Docker Compose

```bash
docker compose up --build
```

Access the application:

```text
http://localhost:8080
```

Stop the container:

```bash
docker compose down
```

### Docker Architecture

```text
Developer
    |
    v
React + TypeScript
    |
    v
Vite Production Build
    |
    v
Docker Multi-Stage Build
    |
    v
Nginx Alpine Server
    |
    v
Portfolio Application
```
